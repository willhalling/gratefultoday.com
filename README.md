# Grateful Today

A daily gratitude journaling application to help cultivate mindfulness and appreciation.

## About

Grateful Today is a simple, elegant platform for daily gratitude practice. Track your daily blessings, read inspiring quotes, and build a consistent gratitude habit.

## Features

- **Daily Gratitude Journal** - Record what you're grateful for each day
- **Inspirational Quotes** - Browse curated collection of uplifting quotes
- **Gratitude Wall** - Share gratitude with the community
- **Affirmations** - Daily positive affirmations for mindfulness
- **Sobriety Chips** - Track recovery milestones with customizable chips
- **Mobile Responsive** - Works beautifully on all devices

## Tech Stack

- **Frontend**: Next.js 15 with App Router
- **Styling**: Tailwind CSS
- **Backend**: Firebase (Firestore, Auth)
- **Deployment**: Vercel

## Development

This app runs as a standalone Next.js project.

### Getting Started

```bash
# Install dependencies
yarn install

# Start development server
yarn dev

# Build for production
yarn build
```

### Project Structure

