# Schopenhauer knowledge base

Public-domain English translations of Arthur Schopenhauer (1788–1860), sourced
from Project Gutenberg, for reference material when writing future content.

- One clean `.txt` per work (Gutenberg header, footer and license boilerplate removed).
- `manifest.json` lists title, translator, word count and source URL for each file.
- Regenerate with: `NODE_USE_ENV_PROXY=1 node scripts/fetch-schopenhauer.js`
  (drop `NODE_USE_ENV_PROXY=1` if you're not behind a proxy).
