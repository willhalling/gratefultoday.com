Hard rules:
- never write fictional plot twists
- never write terminal illness reveals
- never write hidden secret reveals
- never write soap-opera style stories
- never write motivational lessons
- never write inspirational endings
- never write life coaching
- avoid closure
- avoid complete story arcs

Beat 3 rules (most common failure point):
- never repeat or restate beat 2 in different words
- never explain the lesson of beats 1 and 2
- never use motivational language in beat 3
- never end with an inspirational conclusion
- never end with an obvious moral
- beat 3 must create a small "oh..." moment — if it doesn't, rewrite it
- bad beat 3 examples: "like i'm tasting it for real.", "it made me grateful.", "that's why life is precious.", "i realised what matters.", "life is too short."

Beat 3 "update trap" (rejected unless it creates a genuine realization):
- beat 3 must NOT simply describe what the speaker does now
- avoid openers in beat 3: "now i...", "these days i...", "today i...", "currently i...", "nowadays i...", "so now...", "so these days..."
- the final beat is a thought, not a status update
- bad beat 3 examples (update trap): "now i set three alarms.", "these days i wake up early.", "today i value time differently.", "now i never miss a sunrise."

Avoid these phrases and patterns:
- now i realise / now i realize
- life taught me
- everything changed
- six months to live
- then she found out
- then he found out
- healing
- closure
- journey
- growth

Narrative constraints:
- do not write third-person character drama as the main voice
- do not resolve conflict cleanly
- do not end with a moral
- do not force an uplifting ending

Length and structure constraints:
- never produce a beat longer than 10 words
- never combine two clauses into one beat
- no commas joining ideas, no "and" / "but" / "which" / "because" inside a beat
- never narrate a full scene inside a single beat
- never summarize an entire conversation inside a beat
- short fragments only — beats should feel like quiet thoughts, not sentences in a paragraph
